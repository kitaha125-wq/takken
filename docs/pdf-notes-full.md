## 建築基準法まとめノート（前編）

> 分野: 法令上の制限

### 第1章 建築基準法の目的と基本構造

建築基準法は、国民の生命・健康・財産を守るために、建築物の敷地・構造・設備・用途などについて最低限の基準を定めています。 目的は「安全・衛生・環境・防災・景観の確保」です。

| 分類 | 内容 |
| --- | --- |
| 建築物 | 屋根と柱または壁があり、土地に定着しているもの（プレハブや倉庫も含む） |
| 工作物 | 煙突・広告塔・塀など、建築物以外で土地に定着している構造物 |
| 特定行政庁 | 建築行政を担当する自治体の長（札幌市長など） |
| 建築主事 | 建築確認を行う国家資格者 |
| 指定確認検査機関 | 民間で建築確認・検査を行う機関 |

### 第2章 用途地域ごとの建築制限

用途地域によって建てられる建築物の種類が制限されます。

13種類の用途地域それぞれに、住居・商業・工業のバランスを考えた用途制限があります。

| 用途地域 | 主な建築可否 |
| --- | --- |
| 第一種低層住居専用地域 | 住宅中心。小規模店舗や兼用住宅のみ可。飲食店・ホテル不可（許可があれば小規模飲食店可）。 |
| 第二種低層住居専用地域 | 第一種よりやや緩和。小規模店舗・事務所併設可。 |
| 第一種中高層住居専用地域 | 中高層住宅中心。大学・病院は可。ホテルは不可。 |
| 第二種中高層住居専用地域 | 第一種より緩和。ホテル・旅館は原則不可。 |
| 第一種住居地域 | 住宅中心。一定規模の店舗・事務所・学校可。 |
| 第二種住居地域 | 幹線沿いを想定。パチンコ店・カラオケボックス可。 |
| 準住居地域 | 道路沿いを想定。自動車修理工場・ホテル可。 |
| 近隣商業地域 | 日用品店・映画館可。10,000㎡超の大型店も可。 |
| 商業地域 | 銀行・デパート・オフィスなど。住宅も可。 |
| 準工業地域 | 軽工業中心。住居と共存可。 |
| 工業地域 | 環境悪化をもたらすおそれのない工業中心。 |
| 工業専用地域 | 住宅・学校など不可。 |
| 田園住居地域 | 農地と調和する低層住宅中心。 |

#### 特別用途地区：国交大臣の承認を得て条例で用途制限を緩和できる。 ✅

幼保連携型認定こども園：全用途地域で建築可。 ✅兼用住宅：非住宅部分が延べ面積の1/2未満・50㎡以下なら建築可（工業専用地域を除く）。

### 第3章 建ぺい率・容積率・高さ制限

建築物の規模を制限する代表的な基準が「建蔽率」と「容積率」です。

| 項目 | 内容 |
| --- | --- |
| 建蔽率（けんぺいりつ） | 敷地面積に対する建築面積の割合。防火地域内で耐火建築物なら＋10％緩和（限度8/10なら制限なし）。 |
| 容積率 | 敷地面積に対する延べ床面積の割合。前面道路の幅員が12m未満の場合は、幅員×法定係数（例：4m×4/10＝160％）で上限を決定。 |
| 絶対高さ制限 | 低層住居系では10mまたは12mを上限。都市計画で定められた方を超えてはならない。 |
| 外壁後退 | 第一種・第二種低層・田園住居地域では1mまたは1.5m後退を都市計画で設定可能。 |
| 北側斜線制限 | 低層・中高層住居専用・田園住居地域で適用（日影規制がある場合を除く）。 |

### 第4章 防火・準防火地域と構造制限

防火地域・準防火地域では、火災の延焼を防ぐために構造制限が設けられています。

**防火地域**
- 主要構造制限: すべての建築物は原則耐火建築物。延べ面積1000㎡超は防火壁で区画。
- 補足: 耐火建築物なら建蔽率制限なし。

**準防火地域**
- 主要構造制限: 地階を除く階数4以上、または延べ面積1500㎡超は耐火建築物または延焼防止建築物。
- 補足: 準耐火建築物では不可。

**防火構造・準耐火構造・耐火構造**
- 主要構造制限: 防火＝外壁・軒裏等を燃えにくく、準耐火＝30分、耐火＝1時間以上の火災抵抗性能。
- 補足: 屋上の看板・広告塔（高さ3m超）は不燃材料で造る。

#### まとめポイント - 防火地域＝最も厳しい。すべて耐火建築物義務。 -

準防火地域＝延べ面積1500㎡超・4階以上は耐火または延焼防止建築物。 -広告塔や屋上工作物（高さ3m超）は不燃材で造る必要あり。

## 建築基準法まとめノート（後編）

> 分野: 法令上の制限

### 第8章：防火・避難設備

- 延べ面積1,000㎡超の建築物 → 防火壁・防火床で区画（各区画1,000㎡以内） ※耐火建築物・準耐火建築物は例外
- 階段部分の排煙設備 → 床面積800㎡以下の建物は不要
- 特殊建築物（映画館・ホテル・病院など） → 用途変更200㎡超は建築確認必要
- 高さ20ｍ超 → 避雷設備設置義務
- 防火地域内の広告塔・看板 → 高さ3ｍ超や屋上設置は不燃材料で造る

### 第9章：確認・検査制度

- 建築主は工事完了後、建築主事または指定確認検査機関による完了検査を受ける義務
- 防火地域内の大規模建築物（階数2以上・延べ200㎡超）は、10㎡以内の増改築でも確認・検査が必要
- 大規模建築物・特殊建築物 → 原則として検査済証交付後でなければ使用不可
- ただし、安全上問題がないと認められた場合は「仮使用認定」で使用可

### 第10章：違反建築物への対応

- 是正命令：違反を発見した場合、工事停止・除却・使用禁止などを命令可能
- 仮命令：緊急の必要がある場合、手続を省略して仮の命令が可能（工事停止・使用制限など）

### 第11章：構造・安全基準

- バルコニー・屋上広場など2階以上の部分には手すり高さ1.1ｍ以上必要
- 避難階以外の階で物品販売業を営む店舗（売場1,500㎡超） → 2以上の直通階段を設置
- 居室の換気開口部：床面積の20分の1以上
- 居室の採光開口部：床面積の7分の1以上
- 居室の天井高さ：2.1ｍ以上（平均値で判断）

### 第12章：道路・接道・安全通路

- 前面道路が2本以上ある場合 → 容積率は「最大の幅員（12ｍ未満）」で算定
- 建築基準法第68条の9第1項 → 幅員4ｍ（または指定区域は6ｍ）以上の現存道路は法上の道路とみなす
- 敷地が袋路（行き止まり道路）にのみ接する場合 → 延べ150㎡超（戸建除く）は条例制限あり
- 避難通路：延べ200㎡未満なら幅0.9ｍ、その他は1.5ｍ以上

## 法令上の制限まとめリスト（簡易）

> 分野: 法令上の制限

#### 都市計画法

- 用途地域：12種類（住居系、商業系、工業系など）
- 市街化区域・市街化調整区域：線引き都市計画区域に指定
- 開発許可：原則1,000㎡以上（非線引き区域は3,000㎡以上）
- 建築制限：用途地域ごとに建ぺい率・容積率の上限が定められる

#### 建築基準法

- 接道義務：幅員4ｍ以上の道路に2ｍ以上接すること
- 建ぺい率：原則30〜80％、角地緩和あり
- 容積率：建築面積×容積率＝延べ床面積の上限
- 高さ制限：絶対高さ（10ｍ・12ｍ）、斜線制限（日影規制含む）

#### 農地法

- 農地転用には許可必要（3条：権利移転、4条：自己転用、5条：譲渡＋転用）
- 無許可転用は原状回復命令あり

#### 盛土規制法

- 宅地造成等規制法に加え、全国一律で盛土規制が強化
- 大規模盛土造成地マップによる調査義務

#### 土地区画整理法

- 仮換地制度：事業中に土地利用を可能にする仕組み
- 換地処分後、従前地の権利は消滅し、新しい換地に移行

#### 国土利用計画法

- 一定面積以上の土地取引は事前届出が必要（市街化区域：2,000㎡、非線引き：5,000㎡、都市計

画区域外：10,000㎡）

- 事後届出が不要なケース：国・地方公共団体との取引など

## 法令上の制限まとめリスト（都市計画法・建築基準法など）

> 分野: 法令上の制限

#### 都市計画区域・準都市計画区域

- ・都市計画区域は原則：都道府県が指定、例外：国土交通大臣（都府県をまたぐ場合）。
- ・準都市計画区域は区域区分は定められないが、8種類の地域地区は設定可能。
- ・準都市計画区域に設定可能な地域地区：用途地域、特別用途地区、特定用途制限地域、高度地区(最高限度のみ)、景観地区、風致地区、緑地保全地域、伝統的建造物群保存地区。

#### 用途地域（13種類）

- ①第一種低層住居専用地域：低層住宅の良好な住環境を守る。
- ②第二種低層住居専用地域：低層住宅＋小規模店舗等。
- ③第一種中高層住居専用地域：中高層住宅向け。
- ④第二種中高層住居専用地域：中高層住宅＋小規模店舗。
- ⑤第一種住居地域：住居環境を守りつつ中規模店舗可。
- ⑥第二種住居地域：大規模店舗・事務所も可。
- ⑦準住居地域：幹線道路沿いの自動車関連施設等も可。
- ⑧近隣商業地域：近隣住民向け店舗中心。
- ⑨商業地域：商業・業務の中心。
- ⑩準工業地域：環境悪化を伴わない工業中心。
- ⑪工業地域：あらゆる工業可能（住宅も可）。
- ⑫工業専用地域：工業専用、住宅は不可。
- ⑬田園住居地域：農業と住居の調和。

#### 地域地区（用途地域内に定められるもの）

- ・特別用途地区：用途地域の補完。
- ・高度地区：高さの最高限度/最低限度を設定。
- ・高度利用地区：容積率・建ぺい率・建築面積最低限度を設定。
- ・高層住居誘導地区：高層住宅の誘導（容積率400％/500％の住居系等）。
- ・特例容積率適用地区：容積率の未利用分を活用（低層住居・工業専用地域は除外）。

#### 開発許可が不要な場合（代表例）

- ・公益上必要な建築物（駅舎、図書館、公民館、変電所、公園施設など）。
- ・都市計画事業、市街地再開発事業、土地区画整理事業として行う場合。
- ・自己居住用住宅（市街化調整区域100㎡程度など一部例外あり）。

#### 開発許可が必要な面積基準

- ・市街化区域：1,000㎡以上。三大都市圏特定市は500㎡以上。
- ・市街化調整区域：原則すべて許可必要。
- ・非線引区域：3,000㎡以上。
- ・準都市計画区域：3,000㎡以上。
- ・都市計画区域外：10,000㎡以上。

#### 建築基準法関連（容積率・建ぺい率）

- ・容積率＝延べ床面積 ÷ 敷地面積。
- ・建ぺい率＝建築面積 ÷ 敷地面積。
- ・道路幅員制限：前面道路幅員×0.4（住居系用途地域）を上限とする。

## 農地法まとめ

> 分野: 法令上の制限

- 農地法の目的は、農地の権利移動・転用を規制し、耕作者による適正かつ効率的な利

用を確保すること。

- 農地：耕作の目的に供される土地。採草放牧地：主として牧草の採取または家畜の放

牧に利用される土地。

- 農地法は、農地・採草放牧地の権利移転・転用・転用目的の権利移転に関するルール

を定める。

### 第2章 権利移転・転用の許可制度

- 農地法3条：農地を農地として権利移転・設定する場合 → 農業委員会の許可が必要。
- 農地法4条：農地を農地以外に転用する場合 → 都道府県知事の許可が必要。
- 農地法5条：転用を目的として権利を移転・設定する場合 →

都道府県知事の許可が必要。

- 許可は原則事前許可。事後許可制度はなし。

### 第3章 許可不要（届出）となるケース

- 3条：農地→農地の権利移転で、農業委員会の許可対象外となる場合は届出。
- 4条・5条：市街化区域内では、開発許可または建築確認を受けた場合、届出により足

りる（許可不要）。

- 国または地方公共団体の事業に伴う転用も許可不要の例外あり。

### 第4章 許可基準と判断

- 3条許可基準：適正かつ効率的な農地利用が確保されるかどうか。
- 4条・5条許可基準：転用後の土地利用の確実性・公共性・周辺農地への悪影響の有無

など。

- 権利移転の相手が農業従事者であること、転用計画の実現性があることが重要。

### 第5章 違反・罰則・効力

- 無許可転用の場合、その契約は効力を有しない（無効）。
- 知事等による原状回復命令の対象となる。
- 罰則もあり、違反は行政・刑事両面で制裁対象となる。

### 第6章 数字・用語・ひっかけ注意まとめ

- 許可権者：3条→農業委員会、4条・5条→都道府県知事。
- 許可不要の届出制度：市街化区域内での転用・転用目的の権利移転（4条・5条）が代

表例。

- 農地の権利移転は事前許可が原則。事後許可制度はない。
- 『許可不要』と『許可が不要になる』は異なる（都市計画法との連動に注意）。
- 採草放牧地も農地法の適用対象となる。
- 農地転用許可の有無により、契約の有効性が変わる（無許可転用は無効）。

<a id="都市計画法まとめノート-中編"></a>

## 都市計画法まとめノート（中編）

> 分野: 法令上の制限

### 第1章 用途地域（13種類の比較整理）

用途地域は、建築できる用途を制限して住環境を守る制度です。住居系・商業系・工業系に分類されます。

**住居系**
- 地域名: 第一種低層住居専用地域
- 主な建築物: 専用住宅・小中学校など
- 特徴・建築制限の概要: 建物高さ10mまたは12m、店舗等不可（特定行政庁許可で可）

**住居系**
- 地域名: 第二種低層住居専用地域
- 主な建築物: 専用住宅・小規模店舗（150㎡以内）

<a id="都市計画法まとめノート-前編"></a>

## 都市計画法まとめノート（前編）

> 分野: 法令上の制限

#### 都市計画法の概要と体系

都市計画法は、「都市の健全な発展と秩序ある整備」を目的とする法律で、都市空間を総合的に整備・開発・保全するための枠組みを定めています。

#### 【構成の全体像】 ① 都市計画区域の指定 ②都市計画の内容（地域地区・都市施設・市街地開発事業） ③ 開発行為の許可制度 ④

都市計画事業の実施・制限

> ⚠ 試験の狙いどころ：『どの区域に何が定められるか』『許可不要なケース』の区別。

#### 都市計画区域・準都市計画区域

都市計画区域は「都市として計画的に整備すべき区域」で、都道府県が指定します。 一方、準都市計画区域は「都市計画区域外でも、土地利用の整序や環境保全が必要な区域」に指定されます。

**都市計画区域**
- 指定主体: 原則：都道府県（2以上にまたがる場合：国交大臣）
- 区域区分: あり（市街化区域／調整区域）
- 定められる地域地区: ほぼすべての地域地区
- 特徴: 都市として一体的に整備

**準都市計画区域**
- 指定主体: 都道府県
- 区域区分: なし
- 定められる地域地区: 用途地域・風致・景観・緑地など８種のみ
- 特徴: 非線引き区域に近い

#### 覚え方：準都市計画区域＝“都市計画のミニ版”。区域区分はないが用途地域は設定できる。

#### 区域区分（線引き制度）

都市計画区域内では、無秩序な市街化を防止し、計画的な市街地形成を進めるため、「市街化区域」と「市街化調整区域」に区分されることがあります（＝線引き制度）。

| 区域 | 内容 | 許可の原則 | |------|------|------------| | 市街化区域 |すでに市街地を形成している、または10年以内に市街化すべき区域 |原則、開発可能（ただし1,000㎡以上は許可必要） | | 市街化調整区域 | 市街化を抑制すべき区域 |原則、開発禁止（公益目的など一部例外のみ） | | 非線引き区域 | 区域区分を定めない都市計画区域 |3,000㎡以上の開発は許可必要 |

> ⚠ ひっかけ注意：「準都市計画区域」には区域区分がないが、用途地域は定められる。

## 都市計画法まとめノート（後編）

> 分野: 法令上の制限

### 第1章 開発許可が必要な行為と不要な行為

「開発行為」とは、主として建築物の建築または特定工作物の建設のために行う土地の区画形質の変更をいいます。 開発許可が必要かどうかは、区域・面積・目的によって判断されます。

区域区分

許可が必要となる面積

許可不要の例

1,000㎡以上（※三大都市圏特定市は500㎡）

駅舎・図書館・公民館・変電所など公益建築物

非線引き都市計画区域

3,000㎡以上

土地区画整理事業・市街地再開発事業による開発行為

### 第2章 開発許可の権限・手続き

開発許可を与えるのは原則として都道府県知事です。

ただし、2つ以上の都府県にまたがる開発については国土交通大臣が権限を持ちます。

| 項目 | 内容 |
| --- | --- |
| 権限者 | 原則：都道府県知事／例外：国土交通大臣（2都府県にまたがる場合） |
| 公告手続き | 許可の公告後は開発行為が正式に認可されたことを意味する |
| 認可後の制限 | 公告前の建築は原則禁止。ただし仮設建築物・同意していない者の建築は例外 |
| 届出義務 | 認可の公告後に土地や建物を譲渡しようとする者は施行者に届出が必要（許可は不要） |

### 第3章 技術的基準（第33条）

開発許可を受ける際には、都市の健全な発展を図るための技術的基準（第33条）に適合していなければなりません。 特に「土砂災害特別警戒区域」を含む開発は禁止されています。

| 区分 | 内容 |
| --- | --- |
| 立地基準 | 自己の業務のための施設開発では、土砂災害特別警戒区域を含む土地は開発禁止 |
| 施設基準 | 道路・公園・排水施設等を適切に配置し、安全かつ衛生的であること |
| 公共施設の整備 | 開発区域外の道路・上下水道との接続を確保 |
| 保安基準 | 急傾斜地・地盤不良地などは造成方法に制限あり |

### 第4章 特例・関連事業（再開発・地区計画など）

都市計画法では、一定の公共性を持つ事業に対して開発許可を不要とする特例が設けられています。

**都市計画決定時点で公的審査済のため**
- 許可の扱い: 土地区画整理事業
- 理由・補足: 許可不要
- 市街地再開発事業: 区域・面積を問わず既に公共目的で整備されるため
- 許可不要: 地区計画・地区整備計画

**地区単位で整備方針を定め、開発を誘導**
- 許可の扱い: 小規模区域における自主的都市整備計画
- 理由・補足: 工事完了公告前の建築制限
- 市街地再開発事業: 原則禁止
- 許可不要: ただし仮設建築や同意していない者の権利行使は例外

## 借地権まとめ

> 分野: 権利関係

- 普通借地権の存続期間は30年以上。1回目の更新は20年、2回目以降は10年。短縮特約

は無効、延長特約は有効。

- 一時使用目的の借地権は30年ルール、更新、期間延長の規定が適用されず、短期契約
- 更新なし特約が可能。
- 契約方式：普通借地権は口頭でも成立可能。

### 第2章 対抗要件と登記

- 借地権は登記または自己名義の建物登記で第三者に対抗可能。土地の引渡しのみでは

対抗できない。

- 借家権は引渡しによって対抗可能（民法605条）。
- 建物滅失時、掲示で2年間の対抗力猶予あり。2年以内に新築＋登記で復活。掲示だけ

では延長不可。

- 単筆の土地では建物1棟の登記で土地全体に対抗可能。
- 複数筆の土地では、登記された建物の敷地にのみ対抗力が及ぶ（判例）。
- 他人名義の登記は対抗力なし。表示登記でも自己名義であれば可。

### 第3章 定期借地権

- 一般定期借地権：50年以上。用途不問。契約方式は書面または電磁的記録（公正証書

不要）。

- 事業用定期借地権：10年以上50年未満。用途は事業用限定。公正証書による契約が必

須。

- 住宅用＋50年未満の契約 → いずれの定期借地権も設定不可。
- 一般定期借地権では60年など長期契約も可能。

### 第4章 更新と正当事由

- 建物がある＋更新請求→従前と同一条件で法定更新。
- 借地権設定者が正当事由に基づき、遅滞なく異議を述べた場合は更新されない。
- 建物がない場合は更新されない。
- 更新期間：1回目20年／2回目以降10年。
- 借家は柔軟に更新可能（黙示更新あり）。

### 第5章 建物滅失と再築

- 登記建物が滅失した場合、原則対抗力喪失。
- 建物滅失後、所定事項の掲示で2年間対抗力維持。
- 2年以内に新築＋登記で対抗力復活。掲示だけでは不可。
- 再築による借地権の期間延長に反する借地権者不利な特約は無効。

### 第6章 建物買取請求・先取特権

- 借地契約満了＋更新なしの場合、借地権者は建物・附属物の買取請求ができる（借地

借家法13条）。

- 債務不履行による解除の場合、建物買取請求権は認められない（判例）。
- 借地権設定者は弁済期到来の最後の2年分の地代等について、建物に先取特権を有する（民法333条）。

### 第7章 ひっかけ注意＆数字まとめ

- 登記 or 建物登記 → 借地対抗OK。土地引渡しだけ → NG。借家は引渡しでOK。
- 建物滅失 → 掲示で2年猶予 → 新築＋登記で復活。
- 更新期間：1回目20年／2回目以降10年。
- 定期借地権：事業用は公正証書・10年以上50年未満、一般は書面・50年以上。
- 複数筆の土地→登記建物の敷地のみ対抗力が及ぶ。
- 債務不履行による解除→建物買取請求権は不可。
- 一時使用目的→30年ルール適用なし、短期契約・更新なし特約可。

## 売主の担保責任まとめ

> 分野: 権利関係

#### 売主の担保責任とは

売買契約において、目的物に契約内容との不適合（数量・権利・種類・品質）がある場合に、売主が買主に対して負う責任。改正民法では「契約不適合責任」と呼ばれる。

#### 契約不適合の種類

**数量・権利**
- 内容: 目的物の数量や権利関係が契約と異なる
- 具体例: 土地の一部が他人の所有物だった

**種類・品質**
- 内容: 目的物の品質や種類が契約と異なる
- 具体例: 欠陥住宅、規格違い

#### 買主ができる請求

#### ① 損害賠償請求

#### ② 契約解除（重大な場合）

#### ③ 追完請求（修補・代替物引渡し・不足分引渡し）

#### ④ 代金減額請求（追完不能等の場合）

> ※ 買主に帰責事由がある場合は請求不可

#### 期間制限

契約不適合の種類

通知・時効期間

備考

数量・権利

不適合を知ったときから5年

引渡しから10年

消滅時効の原則

種類・品質

不適合を知ったときから1年以内に通知

悪意・重過失の場合は制限なし

#### 試験のひっかけポイント

- 契約不適合＝担保責任（旧法用語）
- 契約解除には「原則催告」が必要（ただし不能などの例外あり）
- 追完請求・代金減額請求が可能になったのは改正民法後
- 悪意・重過失の場合は通知期間制限なし
- 宅建では特に「数量・権利」と「種類・品質」の区別が重要！

<a id="抵当権まとめ"></a>

## 抵当権まとめ

> 分野: 権利関係

#### ① 抵当権とは

抵当権とは、不動産を担保にしてお金を借りるときに設定される権利で、債務者が返済できなくなったときに担保不動産を競売して優先的に弁済を受けることができる権利。

特徴：所有権はそのまま残り、債務者が使い続けられる（非占有担保）。

#### ② 抵当権の効力

抵当権の効力は、担保の目的物およびその代価に及ぶ。

また、利息や定期金の請求権については、満期となった最後の2年分についてのみ抵当権を行使できる（民法第375条）。

> ※これは後順位抵当権者や一般債権者の利益保護のためであり、設定者と物上保証人との関係では適用されない（判例）。

#### ③ 法定地上権

次の4つの要件を満たすと、建物について地上権が設定されたものとみなされる：

#### ① 土地及びその土地上に存在する建物がある

#### ② 同一の所有者に属する場合

#### ③ 土地または建物について抵当権が設定されている

#### ④ 実行により土地と建物の所有者が異なるに至った

この場合、買受人は土地の上にある建物をそのまま利用できる（地上権が認められる）。

#### ④ 一括競売

抵当地に建物が建てられた場合、抵当権者は土地とともに建物も一括して競売できる。

ただし、抵当権の効力は土地のみに及ぶため、優先弁済を受けるのは土地の代価に限られる。

#### ⑤ 抵当建物使用者の引渡し猶予

抵当権に対抗できない賃貸借によって建物を使用・収益している者は、競売により買受人が取得

した場合、

買受人の買受けの時から6か月間は引渡しを猶予される（民法395条）。

#### ⑥ 根抵当権（補足）

根抵当権は将来の不特定の債権も担保できる抵当権の一種。

元本確定前は被担保債権の範囲・債務者の変更等が可能。元本確定後は普通の抵当権と同じ扱いになる。

#### ⑦ 試験で狙われるポイント

#### 抵当権は非占有担保である

#### 利息・定期金は2年分のみ担保

#### 法定地上権の要件4つは頻出

#### 一括競売では土地の代価のみ優先弁済対象

#### 引渡し猶予は6か月

#### 根抵当権＝将来債権も担保

## 時効まとめ

> 分野: 権利関係

#### ① 時効の基本

時効とは、一定期間の経過によって法律上の権利・義務の変動が生じる制度。

#### 取得時効：占有を続けることで権利を取得

❌ 消滅時効：権利が行使されないまま一定期間経過すると権利が消滅

#### ② 取得時効の援用権者

**援用肯定例**
- 内容: 被相続人の占有によって取得時効が完成した場合、共同相続人の1人は自己の相続分の限度でのみ援用できる
- 判例の考え方: 一部援用OK

**援用否定例**
- 内容: 建物賃借人は、賃貸人による敷地所有権の取得時効を援
- 判例の考え方: 用できない

否定される

#### ③ 消滅時効の援用権者

| 援用肯定例 | 援用否定例 |
| --- | --- |
| 保証人・連帯保証人 物上保証人 | 抵当不動産の第三取得者 |
| 後順位抵当権者（先順位の被担保債権の消滅時 | 効を援用できない） |

#### ④ 占有の承継

- 時効進行中に占有者が変わっても、前主の占有を承継できる。
- 承継者は「自分の占有のみで主張」または「前主の占有を併せて主張」が可能。

👉 ただし、前主の占有を併せるときは瑕疵（悪意・欠点）も承継する。

<a id="権利関係-体系まとめ"></a>

## 権利関係 体系まとめ

> 分野: 権利関係

#### 制限行為能力者・意思能力

#### 意思能力

- 意思能力を欠く行為は無効（後見審判の有無にかかわらず）。

#### 未成年者（民5）

- 原則：法定代理人の同意が必要。無断行為は取消可。
- 営業許可未成年者：営業に関しては成年者と同様（同意不要）。
- 同意の範囲・方式：包括同意も可。追認で有効化。

#### 成年被後見人等

- 成年被後見人：原則取り消し得る行為。日用品の購入等は除外。
- 補助・保佐：同意権・取消権の付与の有無に注意。

#### 任意後見・法定後見

- 任意後見：将来の判断能力低下に備え、契約で後見人を選ぶ。
- 法定後見：家庭裁判所の審判で開始（後見・保佐・補助）。

#### 意思表示の瑕疵（錯誤・詐欺・強迫）

#### 錯誤（民95）

- 要素の錯誤＋表意者に重大な過失がない → 取消可。
- 取消権者：表意者本人（および承継人等）。相手方は錯誤を理由に取消不可。
- 効力：取消の遡及。善意第三者保護の射程に注意。

#### 詐欺（民96）

- 相手方の詐欺 → 取消可。
- 第三者の詐欺 → 相手方が善意無過失なら取消不可（相手方保護）。
- 転売先との関係：転得者の善意・悪意で結論が変わる。

#### 強迫（民96）

- 相手方・第三者を問わず取消可（強迫万能）。

#### 虚偽表示（民94）

#### 通謀虚偽表示：無効。

#### 94条2項：善意の第三者に対抗不可（善意第三者最強）。

- 「第三者」＝当事者・一般承継人以外で、表示の目的物につき法的利害関係を有する者。

例：仮装譲受人名義の不動産を差押えた一般債権者、虚偽の抵当権に基づく転抵当権者、仮装債権の譲受人は〇。

×：単なる金銭の貸付をしただけの者。

- 転得者：自ら善意なら保護。悪意から善意への転得でも善意転得者は保護。

#### 代理

#### 基本

- 代理行為の効果は本人に帰属（本人・代理人・相手方の三者関係）。

#### 無権代理（民113～）

- 本人の追認で有効化（原則遡及）。
- 相手方の催告権／取消権。
- 無権代理人の責任（相手方の選択：履行または損害賠償）。
- 無権代理人が本人を単独相続した場合、追認拒絶は信義則違反で不可（判例）。

#### 双方代理・自己契約（民108）

- 原則禁止。本人の「事前の承諾」があれば有効化。

#### 復代理（民104）

- 任意代理人：本人の許諾、またはやむを得ない事由があれば選任可。
- 法定代理人：やむを得ない事由がなくても選任可。

#### 行為能力

- 代理人に行為能力は不要。ただし代理人が後見開始審判を受けると代理権は消滅。

#### 表見代理

- 権限外の行為でも、相手方に正当な理由（善意無過失）があれば本人に効果帰属（判例類推適用）。

#### 占有

#### 基本

- 直接占有／間接占有。占有の適法性は推定。
- 占有は相続により当然承継（相続開始の認識の有無は不問）。

#### 占有訴権

- 回収：占有を奪われたとき（1年）。
- 保持：妨害されたとき。
- 保全：妨害のおそれがあるとき。
- 所有者であっても自ら占有していなければ「占有回収の訴え」は使えない（例：貸主AはBに賃貸中なら占

有者はB）。

#### 時効

#### 取得時効

- 要件：所有の意思・平穏・公然・継続。
- 期間：善意無過失10年／悪意・過失あり20年。
- 承継：相続等により占有の連続が可能。
- 効果：完成により起算時へ遡及して権利取得（遡及効）。

#### 消滅時効（改正民法）

- 原則：権利行使可能時から5年、または客観的起算点から10年。
- 完成猶予・更新事由：
- 請求（訴え提起等）：取下げ・却下・棄却確定は更新効なし。
- 仮差押え・仮処分・差押え。
- 承認（債務の一部弁済・利息支払等）。
- 裁判上の和解が成立した場合：原則として権利の確定・新たな債務名義により時効はリセット（更新の効

果）。

#### 物権変動・登記（不動産）

#### 対抗要件（民177）

- 登記なければ第三者に対抗不可。二重譲渡は先登記者勝ち。

#### 保護されない第三者（対抗不要で勝てる相手）

- 無権利者・不法占拠者・背信的悪意者・登記妨害者（条文・判例）。

#### 賃貸借の対抗

- 土地賃借人が登記ある建物を所有→新所有者に対抗可。
- 新所有者が賃貸人地位を主張し賃料請求するには、移転登記等の対抗要件が必要（判例）。

#### 賃貸借・地上権

#### 修繕義務

- 地上権（物権）：権利者が自己負担で使用収益（原則）。
- 賃貸借（債権）：貸主に修繕義務（民606）。

#### 譲渡・転貸

- 地上権：自由（民266）。抵当権設定も可。
- 賃借権：原則、賃貸人の承諾が必要（民612）。承諾なく転貸・譲渡で解除・明渡請求可。賃借権自体に抵

当権設定は不可（債権譲渡等で担保化は理論上可）。

#### 妨害排除請求

- 地上権者：物権的請求権として不法占拠者に対抗可。
- 賃借人：判例上、使用収益確保のため不法占拠者に妨害排除請求可。

#### 相隣関係

#### 隣地使用権（民209）

- 境界標調査・測量のために必要な範囲で隣地使用可。住家は承諾が必要。承諾得られないときは裁判所の

許可申立て。

#### 枝と根（民233・2021改正）

- 枝：切除請求→相当期間内に不履行なら自力で切取り可。
- 根：請求不要で自力切取り可。

#### 障壁（民225・226）

- 境界線上の障壁は共有推定。
- 高さを増すのに相手の承諾は不要。ただし増設部分の費用は自己負担。

#### 雨水・排水

- 屋根から直接隣地へ注ぐ構造は不可。妨害排除・予防請求可。

#### 袋地通行（囲繞地通行権）

#### 基本（民210～）

- 公道に出られない袋地所有者は必要の範囲で囲繞地を通行可。自由に選べず、最も損害の少ない合理的経

路。

- 原因が分割による場合は無償。それ以外は償金支払が原則。
- 自動車通行：合理的必要性があれば可。

#### 賃貸借との関係

- 通行目的で賃借した通路の賃借権は、要役地の所有権と当然に一体移転しない（賃借権は独立の債権）。

#### 地役権

#### 定義

- 要役地の便益のために承役地を使用する物権。要役地に従たる権利。

#### 時効取得

- 継続的かつ外形上認識可能な態様で行使される場合に限り時効取得可。通路開設が要役地所有者によって

されたことが必要（判例）。

#### 承役地の特定承継人

- 設定行為や契約で負担を負う旨がある場合、特定承継人にも義務が及ぶことがある。

#### 共有

#### 決定原則（民252）

- 保存＝各自単独、管理＝持分価格の過半数、変更＝全員一致。
- 軽微変更（形状・効用の著しい変更なし）は管理扱い＝過半数。

#### 短期賃借権（過半数で設定可：民252②）

- 山林（植栽・伐採目的）＝10年以内、その他の土地＝5年以内、建物＝3年以内、動産＝6か月以内。

#### 所在不明共有者への対応

- 不在者財産管理人の選任で管理可能。
- 所在不明共有者の持分取得制度：裁判所の決定で他の共有者に移転可。所在不明者が現れたら10年以内に

時価相当額の支払で回復請求可。

## 民法まとめ：債権譲渡・不法行為

> 分野: 権利関係

#### 債権譲渡

- 性質上譲渡を許さない債権でない限り、債権は自由に譲渡可能。
- 譲渡制限特約があっても譲渡は有効。
- ただし、譲受人や第三者が悪意・重過失の場合、債務者は履行拒否可能。

▶ 債務者への対抗要件

#### ① 債権者A→債務者Bへの譲渡通知

#### ② 債務者B→債権者Aの承諾

#### ③ 債務者B→譲受人Cの承諾（C→Aの通知は不可）

> ※ 通知・承諾がなければ、旧債権者への弁済は有効。

▶ 第三者への対抗要件

- 確定日付ある通知 or 承諾の先後で優劣が決まる。
- 先に確定日付を得た譲受人が優先する。

#### 不法行為

▶ 使用者責任（民法715条）

- 使用者は被用者が事業執行に関して加えた損害に責任を負う。
- ただし、選任・監督に相当の注意をした場合や注意しても損害が生じた場合は免責。

▶ 使用者の被用者への求償

#### ① 使用者が賠償した場合、被用者に求償できる。

#### ② 信義則上相当と認められる限度での請求にとどまる（判例）。

▶ 土地の工作物責任（民法717条）

- 占有者：過失責任（一次責任）
- 所有者：無過失責任（二次責任）
- 被害者はまず占有者→免責なら所有者へ。

**債権譲渡**
- 分類: 自由に譲渡可能（特約あっても有効）
- 内容: 通知または承諾
- 対抗要件: C→Aの通知は不可／確定日付の先後で優劣
- ポイント: 使用者責任

**事業執行に関する被用者の行為に責任**
- 分類: 選任・監督の注意で免責
- 内容: 信義則に基づき求償制限あり
- 対抗要件: 土地工作物責任
- ポイント: 占有者＝過失責任／所有者＝無過失責任

―

一次→占有者、二次→所有者

<a id="連帯債務と保証債務まとめ"></a>

## 連帯債務と保証債務まとめ

> 分野: 権利関係

#### ① 連帯債務とは

複数の債務者が、それぞれが全額の債務を負う債務。債権者は誰に対してでも全額の弁済を請求できる。

弁済した1人の連帯債務者がいれば、他の債務者も債務を免れる（絶対効）。

#### ② 連帯債務の絶対効

絶対効があるもの

内容

#### ①弁済（代物弁済・供託を含む）

全員の債務が消滅する

#### ② 相殺

一人の債務者による相殺が全員に及ぶ

#### ③ 更改

一人が債権者と新しい契約に切り替えると全員の債務が消滅

#### ④ 混同

債権と債務が同一人に帰した場合、全員の債務が消滅上記以外（免除・時効完成など）は相対効にとどまり、他の債務者には影響しない。

#### ③ 保証債務とは

保証債務とは、他人の債務を担保するために、債務者が履行しない場合に代わって履行する義務を負うもの。

主たる債務が無効・消滅すれば、保証債務も消滅する（付従性・随伴性）。

#### ④ 普通の保証と連帯保証の違い

**普通の保証**
- 催告の抗弁権: 有
- 検索の抗弁権: 有
- 分別の利益: 有
- 付従性・随伴性: 有

**連帯保証**
- 催告の抗弁権: 無
- 検索の抗弁権: 無
- 分別の利益: 無
- 付従性・随伴性: 有

#### ⑤ 保証人の情報提供義務

保証人が主たる債務者の委託を受けて保証した場合、保証人が請求したときは、債権者は遅滞なく主たる債務の残額、利息、違約金、損害賠償額などの情報を提供しなければならない。

#### ⑥ 個人根保証契約

個人根保証契約とは、不特定の将来債務を担保する保証契約。

書面または電子契約で結ぶ必要がある（要式契約）。

保証人は元本・利息・違約金・損害賠償などの全てについて責任を負うが、極度額の範囲に限られる。

#### ⑦ 試験でのひっかけポイント

#### 連帯債務は一人の弁済で全員が免責（絶対効）

#### 弁済・相殺・更改・混同が絶対効、それ以外は相対効

#### 連帯保証は普通保証と違い、催告・検索・分別の抗弁がない

#### 個人根保証契約は書面（電子含む）必須、極度額の定めが必要

#### 保証人の情報提供義務（主たる債務の履行状況を開示）

## 税金まとめ（取得税・固定資産税・登録免許税など）

> 分野: 税その他

- 不動産を取得したときに課税される地方税。相続は非課税。
- 課税標準：固定資産税評価額（売買価格ではない点がひっかけ）。
- 税率：原則4％。住宅軽減あり（3％）。
- 課税時期：取得時。
- 住宅特例（軽減措置）：一定の床面積要件あり。

### 第2章 固定資産税（超頻出）

- 1月1日時点の所有者が納税義務者。
- 税率：1.4％（標準税率）。
- 住宅用地特例：200㎡以下は課税標準1/6、超過部分は1/3。
- 免税点：土地30万円未満、家屋20万円未満、償却資産150万円未満は非課税。
- 新築住宅の減額措置：3年間（耐火構造は5年間）、120㎡まで1/2。

### 第3章 都市計画税（頻出）

- 固定資産税と併課される地方税。
- 課税客体：市街化区域内の土地・家屋。
- 税率：上限0.3％。
- 納税義務者・課税時期は固定資産税と同様（1月1日現在の所有者）。

### 第4章 登録免許税（頻出）

- 不動産登記などの登記手続に課税。
- 税率：売買2.0％、相続0.4％、抵当権設定0.4％など。
- 住宅や相続により軽減措置あり。
- 印紙税と混同しやすいので注意。

### 第5章 印紙税（頻出）

- 課税対象：不動産売買契約書など課税文書。
- 税額は契約金額に応じて定額。
- 軽減措置対象あり（住宅関係など）。

### 第6章 譲渡所得税（頻出）

- 譲渡所得＝譲渡価格−（取得費＋譲渡費用）。
- 所有期間5年以下：短期譲渡（税率39.63％）。
- 所有期間5年超：長期譲渡（税率20.315％）。
- 居住用財産には3,000万円特別控除の特例あり。
- 買換特例もあり（過去問出題あり）。

### 第7章 相続税・贈与税（頻出）

- 相続税の基礎控除：3,000万円＋600万円×法定相続人。
- 贈与税の基礎控除：110万円。
- 登録免許税率：相続0.4％、贈与2.0％。
- 贈与登記は課税対象。

### 第8章 非課税・免税点・特例（頻出）

- 不動産取得税は相続時非課税。
- 固定資産税の免税点：土地30万・家屋20万・償却資産150万未満。
- 住宅用地特例・新築住宅減額措置など軽減制度多数。

## まとめリスト（完全版）

> 分野: 宅建業法

#### 免許関連

- 免許更新：有効期間満了ごと（5年）。更新しないと免許失効。
- 免許替え：本店を他の都道府県に移転するとき必要。有効期間は従前の免許の残りを引き継ぐ

。

- 免許証返納：①免許替えで従前の免許失効、②免許取消し、③亡失免許証の発見、④廃業届出

のとき。更新忘れで失効した場合は返納不要。

- 欠格事由：禁錮以上の刑、宅建業法違反による罰金刑、暴力団関係者など。過失傷害罪など一

部は対象外。

- 任意的免許取消処分と必要的免許取消処分の違い、任意的取消事由（免許条件違反、供託届出

未了、所在不明公告30日経過など）

- 処分権者は免許権者（知事 or 国交大臣）。

#### 営業保証金・保証協会

- 営業保証金：主たる事務所1000万、従たる事務所500万。供託後に届出→事業開始可能。
- 保管替え：金銭のみの供託時に可能。有価証券含む場合は二重供託が必要。
- 営業保証金の変換：供託物を差し替える行為。遅滞なく免許権者へ届出。
- 営業保証金の取り戻し：廃業・免許取消し等で可能。ただし公告が必要（6か月以上）。10年経

過で公告不要。

- 保証協会：社員から分担金を受領→1週間以内に供託。宅建業者は弁済を受けられない（H29改

正後）。

- 不足・還付後対応：通知を受けた日から2週間以内に供託、不足額供託後2週間以内に届出（供

託書写し必要）。

- 営業保証金の供託義務：免許受領から3か月以内に供託届出しなければ、免許権者は催告義務 →

1か月以内に届出なければ取消し可能（任意的取消し）。

- 公告不要ケース：①二重供託による取戻し、②保証協会加入時、③10年経過。
- 保証協会の公告義務：社員の地位喪失時は6か月以上公告。
- 保証協会による弁済業務保証金の取戻し（事務所廃止時、公告不要）。
- 還付充当金：保証協会は弁済あれば通知義務 →

宅建業者は2週間以内に納付。未納なら社員地位喪失→1週間以内に営業保証金供託。

- 保証協会による担保提供請求（加入前の取引で支障あるとき）。

#### 届出関連

- 死亡・破産・合併消滅法人：30日以内に届出。
- 心身の故障：本人・法定代理人・同居親族が30日以内に届出。成年被後見人＝自動欠格ではな

い。

- 事務所設置や名称・所在地変更：30日以内に免許権者へ届出。
- 展示会など案内所設置：10日前までに免許権者＋所在地管轄知事へ届出。
- 役員住所変更は不要（役員氏名は必要）。

#### 帳簿・従業者名簿

- 帳簿：閉鎖後5年間保存（新築住宅売主＝10年）。
- 従業者名簿：最終記載から10年間保存。

#### 取引士関連

- 登録欠格事由：禁錮以上、宅建業法違反の罰金刑など（過失傷害罪は対象外）。
- 取引士証：交付は登録実務講習修了後。更新は5年ごと、期間制限なしで申請可。
- 取引士証返納：登録取消し・死亡・事務禁止処分時。未返納は10万円以下の過料。
- 登録移転：他県の宅建業者事務所に従事する場合に申請可（単なる住所変更では不可）。
- 未成年取引士：登録可だが専任取引士にはなれない。例外＝法人役員で専任みなしあり。
- 講習要件：宅建士証交付・更新には申請前6か月以内の講習受講必須。

#### 重要事項説明（35条書面）

- 相手が業者：交付のみ、説明不要、提示は請求あれば。
- 相手が一般顧客：説明＋交付＋取引士証提示が必要。
- 区分所有建物売買・交換時は「案」段階で説明すべき事項あり（専有部分の用途・共用部分・

専用使用権・修繕積立金・費用減免）。

- 管理会社がいる場合は説明義務あり。
- 保全措置：50万円以上の支払金・預り金受領時に説明義務。
- 定期借地権：期間・更新の有無・終了後の取扱いを説明。
- 既存建物：設計図書・点検記録・確認済証等の保存状況を説明。無ければその旨説明。
- 建物貸借契約：私道負担の説明不要（支払義務なし）。
- 区分所有建物の貸借：専有部分の用途は説明必要だが、専用使用権の規約説明は不要。
- 建物状況調査（インスペクション）：定義・実施者要件あり、説明義務。
- クーリング・オフ：告知は書面で。記載事項＝業者名・住所・免許番号＋買主の氏名住所。発

信主義で効力発生。

#### 37条書面（契約書）

- 必要的記載事項：所在・構造等の特定表示、代金、引渡し・登記時期、代金・交換差金、担保

責任の定め、天災による損害負担（任意的）、保証保険契約の定めなど。

- 担保責任の定めは37条書面には必要だが重要事項説明には不要。
- 取引士証：記名押印は宅建士、交付は従業員でも可。
- 天災不可抗力：任意的記載（定めがあるときのみ）。
- 37条と35条の違い：金額（代金）は37条、保全措置は35条。

#### 契約関連

- 手付解除：相手が履行に着手したら不可（重要強調ポイント）。
- 割賦販売：支払滞納時は30日以上の相当期間を定めて書面催告しなければ解除不可。即時解除

は不可。

- 損害賠償額の予定・違約金：上限＝代金の2割。定めなければ実損ベースで制限なし。
- 割賦販売：登記未了部分2割、その他義務3割で解除可。
- 手付金等の保全措置：完成物件＝10％以下かつ1000万円以下なら不要。未完成物件は厳格基準

。方法：完成物件＝保証・保険・保管、未完成物件＝保証・保険。

- 担保責任に関する特約の制限（2年以上ルールは売買のみ、賃貸には不適用）。

#### 媒介契約

- 一般媒介：期間自由、更新自由、自動更新有効。報告義務なし。レインズ努力義務。
- 専任媒介：最長3か月、更新可（依頼者申出）。自動更新無効。2週に1回報告義務。レインズ7

日以内。

- 専属専任媒介：最長3か月、更新可。自動更新無効。1週に1回報告義務。レインズ5日以内。

#### 報酬関連

- 権利金：居住用以外は売買代金とみなせるが、居住用は不可。
- 居住用以外の賃貸：報酬上限＝借賃1.1か月分（税込）。配分自由。
- 居住用：原則借賃0.55か月分まで。貸主承諾あれば1.1か月分受領可。
- 貸主の承諾メリット：全額借主負担にできる。

#### 工事完了前の契約制限

- 工事完了前は建築確認などの処分後でなければ売買・交換契約を自ら行う、代理・媒介するこ

とはできない。

- ただし貸借契約の媒介は可能（規制対象外）。

#### 不当な履行遅延の禁止

- 対象は①登記、②引渡し、③取引に係る対価の支払に限られる。
- 媒介報酬の支払拒否などは対象外。
