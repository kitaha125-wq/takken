# 試験前要点｜一目まとめ

寝る前・試験直前に、頻出の数字・線引き・ひっかけだけを眺めるための軽量ページです。

## 開き方

- iPhone（Safari）: https://kitaha125-wq.github.io/takken/exam-sheet.html
- リポジトリ内: [`exam-sheet.html`](../exam-sheet.html)
- スタートページからも開けます: [`start.html`](../start.html)

ホーム画面に追加すると、寝る前・試験直前にすぐ開けます。

## 使い方

1. 分野タブ（全部／宅建業法／権利関係／法令上の制限／税その他）で絞る
2. 「数字だけ」「ひっかけ」表示に切り替えて高速復習
3. チェックを付けると端末に保存（今夜の進捗）

## 中身の方針

- 既存の PDF ノート・弱点ノートから、試験に出やすい論点だけを凝縮
- 1行 = 「論点＋答えの数字／線引き＋⚠ひっかけ」
- 媒介契約・開発許可面積などは比較表付き
