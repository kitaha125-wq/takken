# 過去問の低正答｜要点まとめ

バックアップ（`takken-backup-2026-10-08`）から、**過去問（theme-past）の誤答・低正答**を中心に整理したページです。

## 開き方

- GitHub Pages: https://kitaha125-wq.github.io/takken/my-weak-sheet.html
- リポジトリ内: [`my-weak-sheet.html`](../my-weak-sheet.html)
- データ: [`data/my-weak-points.json`](../data/my-weak-points.json)

## 収録内容（拡充後）

| 区分 | 件数の目安 |
|------|------------|
| 過去問の弱点メモ（review notes） | 107件すべてを要点化 |
| 講義メモ（37条・媒介・8種・税など） | 箇条書きを追加 |
| 検証済みひっかけ | 法令突合で確定した行 |
| **合計** | **約193件** |

## 精度の担保

1. `theme-past`（過去問）の低正答を優先
2. `tk_question_review_notes` を主ソース（誤答理由・記憶フック付き）
3. 法令と矛盾する記述は修正（例: 自ら貸主の37条は交付義務なし）
4. 「詳細」に要約を残し、答え一行だけで誤解しないようにした

## まだノートがない過去問

正答率は低いが弱点メモ未作成の過去問が約100件あります。新しいメモやバックアップを送ってもらえれば、同じ形式で追加できます。
