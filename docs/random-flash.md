# ランダム1件（隙間復習）

スマホで開くたびに、まとめた論点を **1件だけランダム表示** します。  
目に触れる回数を増やして、暗記フックを定着させるためのページです。

## 開き方

- GitHub Pages（マージ後）: https://kitaha125-wq.github.io/takken/random-flash.html
- リポジトリ内: [`random-flash.html`](../random-flash.html)
- スタートページからも開けます: [`start.html`](../start.html)

Safari で開いたら「ホーム画面に追加」すると、アプリ感覚で起動できます。

## 使い方

1. 開く → すぐに1件表示
2. 思い浮かべてから「答えを見る」
3. 「次のランダム」で別の論点へ

### モード

| モード | 内容 |
|---|---|
| 記憶フック | 弱点ノート＋まとめPDF（89件） |
| ○×問題 | 過去問風・過去問ベース（44件） |

### フィルタ（記憶フック）

- **誤答多め** … 間違えた論点を優先（おすすめ）
- すべて / 誤答のみ / 弱点 / まとめ
- 業法 / 法令 / 権利 / 税

直近で出した最大18件はしばらく出にくくなります。

## データ更新

弱点ノートや問題集を更新したら:

```bash
npm run build:flash
```

`data/random-flash.json` が再生成されます。
